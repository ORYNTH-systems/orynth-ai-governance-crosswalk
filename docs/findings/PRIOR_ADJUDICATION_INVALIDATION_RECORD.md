# Prior Adjudication Invalidation Record

## Invalidated state

The previous PASS 05A adjudication methodology is invalidated.

The invalidated implementation assigned verdicts through rank ordering and
fixed count allocation.

That approach did not permit the final distribution to emerge independently
from row-level criteria.

Therefore, the following states are invalidated:

- prior compatibility matrix;
- prior evidence-use ledger;
- prior residual-duty registry;
- prior PASS 05A completion marker;
- downstream PASS 05B findings;
- downstream PASS 05C public package;
- any PASS 05D freeze authorization.

## Preserved state

PASS 04A-R2 remains valid because it indexed public evidence without assigning
compatibility verdicts.

## Replacement rule

All replacement verdicts must be produced under the frozen Independent
Threshold Adjudication Specification.

No expected verdict distribution may be defined before adjudication.

The final distribution must be reported only after all 34 row-level decisions
are sealed.
