# Adversarial Verdict Review Protocol

Every provisional requirement receives eight deterministic adversarial attacks:
central duty, applicability, taxonomy mapping, evidence derivation, functional
performance, evidence scope, material residual, and confidence/counterfactual.

R4 produces recommendations only. Final verdicts require PASS 05A-R5
consolidation and explicit human review.

No target distribution, quota, ranking, or top-N allocation is used.
