# Publication Graphics

This directory contains all publication-quality graphics for the ORYNTH AI Governance Crosswalk v1.0.0.

All counts and statistics shown in these graphics are derived from the canonical row-level matrix at `data/public/ORYNTH_AI_GOVERNANCE_CROSSWALK.csv`.

---

## verdict-distribution.png

A bar chart showing the final verdict distribution across all 34 atomic requirements. Includes the explicit note that `ADDRESSED = 0` is deliberate — the adjudication reports architectural correspondence only where the public evidence supports it.

## status-legend.png

Defines all six compatibility states (`ADDRESSED`, `PARTIALLY_ADDRESSED`, `RELATED`, `NOT_APPLICABLE`, `GAP`, `UNRESOLVED`) with their definitions and current release counts. Suitable for embedding in any document that references the matrix.

## repository-architecture.png

A layered diagram of the repository's folder structure, identifying the canonical matrix as the single source of truth and showing the relationship between primary sources, evidence, adjudication, and release artifacts.

## governance-compatibility-workflow.png

A seven-stage process diagram showing how requirements move from primary-source extraction through requirement normalization, taxonomy mapping, evidence indexing, threshold adjudication, adversarial review, and release freeze.

## evidence-traceability-flow.png

A flow diagram connecting primary government records (Executive Order 14409, Minnesota HF 1606 / Chapter 72) through public ORYNTH evidence artifacts to the canonical matrix, verdict provenance, evidence-use summary, and residual-duty registry.

## social-preview.png

GitHub social preview image (1280 × 640 px). Suitable for upload as the repository's social preview in GitHub Settings → Social preview.

## linkedin-announcement.png

LinkedIn announcement graphic (1200 × 627 px). Suitable for use as the image in a LinkedIn post announcing the public release.
