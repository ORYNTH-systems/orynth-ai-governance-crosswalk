# Public Methodology Summary

The crosswalk applies the following deterministic process:

1. define a bounded source corpus;
2. extract atomic source requirements;
3. preserve source actors, dates, deadlines, and operative distinctions;
4. map source requirements into a normalized governance taxonomy;
5. index mechanisms from the public ORYNTH Reference Architecture and
   Architectural Audit Specification;
6. derive supporting evidence through normalized-taxonomy overlap;
7. validate every referenced evidence identifier;
8. assign one bounded verdict to each requirement;
9. record all material residual duties;
10. preserve explicit legal, governmental, certification, safety, and
    implementation boundaries.

## Verdict meanings

- `ADDRESSED` — a directly relevant bounded public architectural mechanism exists.
- `PARTIALLY_ADDRESSED` — direct support exists, but material external duties remain.
- `RELATED` — a relevant mechanism exists but does not perform the substantive duty.
- `NOT_APPLICABLE` — the primary duty is outside the declared architectural scope.
- `GAP` — no sufficiently relevant public mechanism was identified.
- `UNRESOLVED` — evidence was insufficient for another bounded verdict.

## Evidence boundary

The current release uses only:

- ORYNTH Reference Architecture Version 1.0.0;
- ORYNTH Architectural Audit Specification Version 1.0.0.

## Claim boundary

The methodology does not determine legal compliance, government approval,
regulatory certification, implementation certification, safety, correctness,
fitness for purpose, or statutory satisfaction.

This assessment does not establish or guarantee safety.

This assessment does not establish or guarantee correctness.
