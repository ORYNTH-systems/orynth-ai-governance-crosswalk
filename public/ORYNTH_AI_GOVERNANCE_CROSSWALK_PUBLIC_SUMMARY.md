# ORYNTH AI Governance Crosswalk

## Version 1.0.0 — Public Proof Reference

The ORYNTH AI Governance Crosswalk is an evidence-based architectural
compatibility assessment comparing selected United States AI-governance
requirements with mechanisms publicly defined in:

1. the ORYNTH Reference Architecture Version 1.0.0; and
2. the ORYNTH Architectural Audit Specification Version 1.0.0.

The current bounded release evaluates **34 atomic requirements**:

- Executive Order 14409: **25**
- Minnesota HF 1606 / Chapter 72: **9**

The release does not claim complete federal or 50-state coverage.

## What the zero ADDRESSED count means

No requirement is claimed as fully addressed. This is deliberate. The
adjudication did not manufacture ORYNTH coverage or round partial support up to
full support. Zero inflated full-coverage claims is a trust signal, not a
deficiency: it shows the process reports architectural correspondence only
where the public evidence actually supports it.

## Public-mechanism gaps

The release preserves **13 GAP verdicts** — requirements that are
architecturally relevant but for which no qualifying public ORYNTH mechanism
currently exists. Eleven arise in Executive Order 14409 and two in Minnesota
HF 1606 / Chapter 72.

A gap is a valid research result. It is not filled using private, unpublished,
remembered, or separate-ecosystem architecture, and it is not converted into a
favorable inference. The gaps concentrate in federal program operation,
government implementation, vulnerability management, and enforcement functions
that the public architecture does not perform.

## August 1, 2026 distinction

Executive Order 14409 contains a federal implementation deadline for designated
officials. Minnesota HF 1606 / Chapter 72 contains an effective date for direct
statutory restrictions on specified nudification capabilities. These events are
separate and are not represented as the same mandate.
