# ORYNTH AI Governance Crosswalk

## Version 0.1.0 Public Release State

The ORYNTH AI Governance Crosswalk is an evidence-based architectural
compatibility assessment comparing selected United States AI-governance
requirements with mechanisms publicly defined in:

1. the ORYNTH Reference Architecture Version 1.0.0; and
2. the ORYNTH Architectural Audit Specification Version 1.0.0.

The current bounded release evaluates **34 atomic
requirements**:

- Executive Order 14409: **25**

The release does not claim complete federal or 50-state coverage.

## August 1, 2026 distinction

Executive Order 14409 contains a federal implementation deadline for designated
officials.

Minnesota HF 1606 / Chapter 72 contains an effective date for direct statutory
restrictions on specified nudification capabilities.

These events are separate and are not represented as the same mandate.
